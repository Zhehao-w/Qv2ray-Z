Qv2ray-Z
A Windows-focused continuation of Qv2ray 2.7.0 for modern official Xray-core.
Primary release target: Windows 10/11 x64 · Qt 5.15.2 · MSVC 14.2
Runtime packaging: Release builds bundle a pinned official Xray-core and verified Geo routing assets. The exact source commit, component versions and hashes are recorded in release-manifest.json.
Maintenance scope: Modern Xray compatibility, conservative configuration preservation, Windows reliability, and removal of retired or unreachable legacy surfaces.
Repository: github.com/Zhehao-w/Qv2ray-Z
