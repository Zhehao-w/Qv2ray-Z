# Qv2ray-Z v3.1.1

Qv2ray-Z 3.1.1 is a focused Windows maintenance patch.

## Changes

- Stop deploying retired Qt translation bundles in Windows packages.
- Improve Preferences → Inbound Settings sizing so normal window sizes no longer show unnecessary horizontal or vertical scrollbars; scrolling remains available when the page genuinely does not fit.

## Compatibility

- No protocol, routing, runtime, or configuration-semantics changes.
- Windows x64, Qt 5.15.2, and MSVC 14.2 remain unchanged.
- The pinned Xray-core remains v26.3.27, and the verified Geo dependency pins are unchanged from v3.1.0.
