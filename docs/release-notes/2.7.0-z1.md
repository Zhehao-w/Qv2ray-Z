# Qv2ray-Z v2.7.0-z1

This is the first public Qv2ray-Z release based on the upstream Qv2ray 2.7.0 codebase.

## Highlights

- Compatibility with current official Xray-core releases
- VLESS TCP TLS with Vision
- VLESS TCP REALITY with Vision
- REALITY ML-DSA-65 verification (`pqv`)
- Modern VLESS share-link import and export
- Fixed validation of modern Xray configurations
- Automatic discovery of the bundled Xray executable
- Removal of unsupported legacy XTLS modes from the user interface and configuration generation

Windows x64 is the primary tested release target. Linux and macOS packaged releases are not provided or release-tested for v2.7.0-z1.

The Windows download includes Qv2ray-Z, the Qt runtime and plugins, the latest official stable Xray-core available when the release is built, and the corresponding `geoip.dat` and `geosite.dat` files. Verify the ZIP with its accompanying SHA256 checksum before use.

Qv2ray-Z preserves the GPLv3 license, original Qv2ray attribution, and existing configuration identity for compatibility with current users.
