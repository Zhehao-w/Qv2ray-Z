# Qv2ray-Z v3.2.1

## Changes

- Open the AppContainer Loopback manager directly from the **Loopback** button next to **Groups** in the Windows main window.
- Identify the exemption status dropdown by its funnel icon.

The package targets Windows 10/11 x64 with Qt 5.15.2 and MSVC 14.2. It includes the pinned official Xray-core v26.3.27 and verified Geo routing assets.
