# Qv2ray-Z v3.0.0

Qv2ray-Z 3.0.0 is the first stable release of the modernized Windows-focused client line.

## Highlights

- Modern VLESS + TLS + Vision support
- Modern VLESS + REALITY + Vision support
- REALITY ML-DSA-65 verification (`pqv`)
- Modern VLESS share-link import and export
- Bundled pinned official Xray-core with `geoip.dat` and `geosite.dat`
- Automatic bundled-Xray discovery
- Simplified routing modes:
  - Global Proxy
  - Bypass Mainland China
  - Direct
  - Custom
- Improved Mainland China routing behavior
- Flat connection-list view with optional Grouped view
- Clear separation of user-visible connection Name and Xray outbound Tag
- Modernized Windows Qt5 interface and preferences
- Improved packaging, release reproducibility, regression coverage, and compatibility checks

## Security and legacy cleanup

- Retired third-party native plugin discovery and loading
- Retired the legacy Plugin Manager and obsolete plugin command surfaces
- Retired unsupported Browser Forwarding runtime generation
- Retired legacy theme switching and bundled runtime translation switching
- Retired the in-app updater, executable handoff, and updater persistence state
- Kept first-party protocol and subscription support in-process
- Preserved configuration compatibility for retired persisted keys and legacy updater state

## Compatibility

Existing Qv2ray configuration identity is preserved for compatibility. Legacy configuration keys removed from the maintained runtime are ignored when loading and are not written back on future saves.

Normal connection import, subscription handling, routing, System Proxy, Bypass Mainland China, single-instance forwarding, and supported `qv2ray://` behavior remain available.

## Platform

Windows x64 with MSVC is the primary supported and release-tested target. Linux remains diagnostic-only and macOS/Android are not supported release targets.

The release package includes:

- Qv2ray-Z
- Qt runtime and required plugins
- Pinned official Xray-core
- `geoip.dat`
- `geosite.dat`
- `release-manifest.json`
- SHA-256 checksum for the release archive
