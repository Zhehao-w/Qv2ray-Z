# Qv2ray-Z v3.2.0

Qv2ray-Z 3.2.0 adds a Windows AppContainer loopback exemption manager for apps that need to reach a local system proxy. It can help troubleshoot connectivity for Microsoft Store and UWP apps, as well as packaged apps such as Microsoft Teams.

## AppContainer loopback exemptions

Open **Preferences → General → AppContainer Loopback → Manage…** to view app names, package details, and exemption status. Search or filter the list, toggle an individual exemption, or apply a change to multiple selections. Groups use Windows package family and parent-child SID information to help you enable verified related containers together.

**Enable All** and **Disable All** cover the entire detected list regardless of search or filter settings. Bulk changes show their scope before applying, and enabling all reduces local network isolation for those apps. Use **Unmatched exemptions** to remove rules whose AppContainer no longer appears in the detected list.

Windows may request administrator approval when a change is needed. The manager reloads the Windows exemption state after each change. Windows keeps the settings when Qv2ray-Z disconnects or closes. Use **Refresh** to detect newly installed apps, then choose whether to exempt them.

## Windows package

The release targets Windows 10/11 x64 with Qt 5.15.2 and MSVC 14.2. The package includes the pinned official Xray-core v26.3.27, verified Geo routing assets, and a release manifest.
